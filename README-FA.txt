نسخه‌ی موبایل (ریپوی CT) - به‌روزرسانی ۵ (نسخه‌ی بررسی‌شده و اصلاح‌شده‌ی به‌روزرسانی ۴)

نصب: توی گیت‌هاب ریپوی CT ← Add file ← Upload files ← پوشه‌های app و tests رو از این زیپ بکش ← Commit changes ← Actions ← build-apk ← Run workflow.

نکته‌ی مهم: اگه توی ریپوی CT قبلاً فایل app/src/main/python/ui.html ساخته شده (از زیپ ۴)، حذفش کن: Code ← همون فایل ← سه‌نقطه ← Delete file. جای درست ui.html توی همین زیپ هست: app/src/main/assets/web/ui.html

چی اصلاح شد نسبت به زیپ ۴:
۱) ui.html توی زیپ ۴ جای اشتباه بود (پوشه‌ی python). حالا جای درستشه، پس دکمه‌ی «آپلود» توی صفحه‌ی گوشی هم می‌آد.
۲) cfgforge.py توی زیپ ۴ نسخه‌ی ویندوز بود و تنظیم DNS اندروید (android_dns) رو نداشت؛ ممکن بود DNS روی گوشی خراب بشه. اینجا نسخه‌ی اندروید + حالت آپلود ادغام شده.
۳) اندروید: خطای «ممنوع» (کد ۱۳) معمولاً محدودیت کل دستگاهه (دیتاسیور، فایروال، پس‌زمینه). دیگه آدرس‌ها رو ۷ روز «سوخته» نمی‌کنه.
۴) تست t30 گاهی بی‌دلیل رد می‌شد (حدود ۲۰٪)؛ اتاق تست تکامل با یک تست ردشده وصله رو نصب نمی‌کرد. درست شد.
۵) سقف زمان اتاق تست از ۶۰۰ به ۹۰۰ ثانیه رفت (تست‌ها بیشتر شدن).
